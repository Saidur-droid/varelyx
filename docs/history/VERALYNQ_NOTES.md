# Historical Brand Note — Veralynq

This file intentionally preserves the earlier founder-facing note that preceded the Varelyx brand decision. It is retained for context and traceability only. **Current brand: Varelyx.**

---

নাম: **Veralynq**

উচ্চারণ: **ভেরা-লিঙ্ক**

Brand idea: **Verified truth → connected decisions → confident action.**

আমার current web + GitHub sweep-এ **Veralynq নামে obvious active retail/software company বা GitHub repo পাইনি**। Domain/trademark কিনবার ঠিক আগে final registrar/legal check করব—তখনই 100% confirm করা যাবে।

**GitHub repo:** `veralynq`

**Description:** *Decision infrastructure for retail disruptions, from incomplete evidence to verified, executable recovery plans.*

### Google নিয়ে

হ্যাঁ, **পুরো plan Google-first করেই করছি**। Gemini/Gemma, Google ADK/Agent Platform, BigQuery + BigQuery ML, Cloud Run/Firebase, Firestore/Cloud Storage—এসব product-এর core engine হবে, শুধু submission decoration না। এটিই competition-এর official requirement-এর সঙ্গেও aligned।

### Business potential

আমাদের target ছোট দোকানকে individually subscription বিক্রি করা না; **FMCG distributor, retail chain, pharmacy/grocery network** হবে customer।

একটা aggressive but achievable planning scenario:

**25 customers × ৳24 লাখ/year = ৳6 কোটি ARR**

**30 customers × ৳25 লাখ/year = ৳7.5 কোটি ARR**

তারপর retention + strong growth প্রমাণ করতে পারলে private SaaS valuation multiples materially improve করতে পারে। Earlier planning discussion used a scenario where approximately **৳12–15 কোটি ARR** combined with strong SaaS quality could support a much larger company valuation. This was always a planning scenario, not a guaranteed valuation.

**Original intent:** Veralynq-কে hackathon project হিসেবে না, real venture-scale company হিসেবেই plan করা।

---

## Why the brand changed

Veralynq was later replaced by **Varelyx** as the preferred working brand/repository identity.

The product thesis did not become weaker; it became sharper:

- from broad retail decision infrastructure;
- to evidence-driven retail continuity;
- from generic “AI decides” messaging;
- to **Known / Estimated / Unknown → Next Best Question → Continuity Twin → Robust Optimizer → Proof Gate → Human-approved execution**.

The current source of truth is the Varelyx documentation at repository root and `docs/`.
